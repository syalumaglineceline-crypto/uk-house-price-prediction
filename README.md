# Forecasting Future Trends in the UK Housing Market

Machine learning and neural-network forecasting of UK house prices, developed as an MSc Business Analytics industry project with Asset Dreams.

## Project Background

This project was completed as part of my MSc in Business Analytics at Aston University, UK, in collaboration with Asset Dreams, a UK real-estate company.

The aim was to investigate the key factors influencing UK house prices and develop predictive models that could support data-driven property-market analysis and business decision-making.

I managed the analytical workflow from data preparation and exploratory analysis through model development, evaluation and interpretation.

## Project Objectives

- Prepare and analyse UK housing-market and economic data.
- Identify variables associated with changes in house prices.
- Develop and compare predictive modelling approaches.
- Evaluate model performance using appropriate regression metrics.
- Investigate whether machine-learning and neural-network approaches improve predictive performance.
- Translate the analytical findings into practical insights for an industry stakeholder.

## Models Evaluated

The project compared several predictive approaches:

- Linear Regression
- Ridge Regression
- Lasso Regression
- Polynomial Regression
- Artificial Neural Network
- Random Forest Regression
- Hyperparameter-tuned Random Forest

The models were compared using regression evaluation measures including RMSE, MAE and R².

Random Forest produced the strongest predictive performance after hyperparameter tuning and cross-validation.
